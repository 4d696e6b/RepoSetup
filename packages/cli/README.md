# @reposetup/cli

Command-line interface for RepoSetup.

```bash
npx @reposetup/cli --help
```

This is an **alpha** prerelease. Integrations are not all equally mature. Use `--dry-run` before changing an important project.

The library packages `@reposetup/core`, `@reposetup/registry`, and `@reposetup/integrations` are runtime dependencies of this CLI.
