# RepoSetup website artwork

These assets were supplied through the chat **Create RepoSetup logo**, thread
`01a10155-82d9-7d90-804d-a2f08d645624`. The existing RepoSetup logo and six
supporting website graphics were created or assembled there with the built-in
image generation tool on 2026-10-09.

The files were copied unchanged from the original checkout's `assets/website`
directory.
Their bytes were compared with the originals. The original files remain in
place; this website did not regenerate or edit them. `prompts.json` preserves
the supplied generation prompts.

## Files

- `reposetup-logo.png`: horizontal RepoSetup logo, 2172 × 724, transparent.
- `hero-stack.png`: introductory stack illustration, 1536 × 1024, transparent.
- `feature-compose.png`: composition illustration, 1254 × 1254, transparent.
- `feature-preview.png`: plan inspection illustration, 1254 × 1254, transparent.
- `feature-compatibility.png`: compatibility illustration, 1254 × 1254, transparent.
- `setup-flow.png`: decorative setup workflow, 2172 × 724, transparent.
- `section-background.png`: quiet technical background, 1672 × 941, opaque.
- `prompts.json`: original generation prompts and metadata.

## Use in this website

Preserve the images' aspect ratios. The wordmark needs a light surface. Feature
illustrations are supporting artwork, not tiny interface icons. The section
background is a single composition and is not a seamless repeating tile.

Keep navigation, headings, commands, setup steps, and support claims as real
text. Use `RepoSetup` as logo alternative text and empty alternative text for
decorative illustrations when adjacent copy conveys their meaning. Artwork
about compatibility represents validation of declared relationships, not a
guarantee that every combination is supported.

These are local assets included in the static website build. This record does
not indicate a deployment or publication.
