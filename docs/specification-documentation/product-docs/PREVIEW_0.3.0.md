# RepoSetup 0.3.0 change preview

`create`, `add`, and `remove` accept `--diff`. Combine it with `--dry-run` to inspect a plan without executing any installation process or writing project files. Without `--dry-run`, the CLI shows the plan and preview before its normal confirmation step. Existing `--yes` behavior remains available for non-selection commands; selection handoffs still require interactive confirmation.

The preview is a version 1, read-only projection of typed operations and bounded local snapshots. It groups intended file changes as create, modify, preserve, or blocked. Package installation and generator effects are marked unknown, including later file operations that may depend on them. The preview never executes a generator to discover its output. It suppresses source and generated file contents, environment values, and arbitrary file bodies. A JSON plan gains a `preview` field only when `--diff` is requested; the existing plan envelope and operation list remain intact. A blocked preview emits one JSON error envelope with its preview on stderr and no plan on stdout.

The CLI reads at most 64 KiB of an inspected file for deterministic classification. Larger or incompatible files are refused when their contents are needed for a safe edit. Symlinked targets and parent paths are blocked. JSON merges require an existing JSON object; text replacement requires exactly one match, accepting LF or CRLF. Existing `create_if_missing` files and already-present `.env.example` keys are preserved. The preview records a fingerprint of inspected targets and common dependency manifests/locks. It rechecks that fingerprint after confirmation and refuses execution if it changed. This is a pre-execution guard, not a transaction: external generators and package managers may still create files or fail once execution begins, and concurrent changes after the final check remain subject to executor safeguards.

The preview is intentionally conservative. It shows the operation reason and affected path but no inline user-file diff. It does not promise exact lockfile, dependency tree, or generator output. Use `--diff --dry-run` to review, then rerun the command for execution.
